# 天下三分：絵の依頼書（地図・アイコン）

ChatGPT などの画像生成に、地図とアイコンを頼むための依頼書です。
作り方は本体の `docs/ART-QUEUE.md` と同じです。ブロックごとに貼り、**1回の返事で1枚だけ**作ってもらいます。

## 使い方（持ち主向け）
1. 下の「ブロック」を1つだけ、` ``` ` の中をまるごとコピーして ChatGPT に貼る。**ブロック1だけは `sangoku/docs/map-guide.png`（下絵）も一緒に添付する**
2. ChatGPT は1回の返事で1枚だけ作る。できたら「次」と送ると、次の番号を作る
3. できた絵は **Claude Code のチャットにそのまま貼る**。番号も一言そえる（例：「M1」「C1」）。ダウンロードの期限切れを防ぐため、できたらすぐ貼るのがおすすめ
4. 上のブロックほど効果が大きい。気に入らなければ「M1をやり直し。〇〇をもっと△△に」と頼み直してよい

## 優先順位
| 順 | ブロック | 中身 | 効果 |
|---|---|---|---|
| 1 | ブロック1 地図 | 本地図 M1、紙の模様 M2 | 画面の大半を占める。いちばん印象が変わる |
| 2 | ブロック2 都市の記号 | 城（大・中・小・廃城）、旗、本拠の印 など | 地図の上で毎回目に入る |
| 3 | ブロック3 命令アイコン | 開墾〜売買の12命令＋4つ | 操作が分かりやすくなる |
| 4 | ブロック4 数値・能力アイコン | 金・兵糧・兵士…、統率〜魅力 | 情報欄が読みやすくなる |
| 5 | ブロック5 戦と出来事 | 一騎打ち・火計・落城・災害 など | 報告や記録に演出がつく |
| 6 | ブロック6 窓の枠 | 窓・ボタンの枠 | 仕上げ |

## 決まり（全部のブロック共通。ブロックの文にも書いてある）
- **画風**：中国の古地図と、宋〜明の山水画（水墨に淡い彩色）。絹や古い紙の質感。差し色は金と朱
- **ゲーム画面の色**：暗い紺 `#11151f`（背景）、金 `#d9b45a`（枠・見出し）、朱 `#6b2a1f`（決定ボタン）、文字は生成り `#ece4d0`
- **文字を絵に入れない**：漢字・ひらがな・数字・ロゴを描かない。都市名などはゲームが上から書く（画像生成は漢字をよく崩すため）
- **市販ゲームのまねをしない**：「三國志」シリーズなど特定のゲームの画面・地図・アイコン・顔グラフィックを参考にしたり、似せたりしない（このゲームは公開されているので、権利の線を守る）
- **勢力の色を描かない**：勢力の色（21勢力ぶん）はゲームが塗る。城は無彩色、旗は白〜灰で描き、ゲームが色を重ねる
- **小さく表示される**：アイコンはゲームで 22〜40px。細かい描き込みより、太い輪郭と2〜3色のはっきりした形を優先

## ブロック1：地図（M1・M2）
**M1 は `sangoku/docs/map-guide.png` を一緒に添付する。**
```
これから歴史シミュレーションゲーム（古代中国・後漢末〜三国時代）の絵を順番に作ってもらいます。ルールを守ってください。
- 1回の返事で作る絵は1枚だけ。作ったら、絵の番号と「次は○番」とだけ書いて止まる。私が「次」と送ったら次を作る
- 画風：中国の古地図と、宋〜明の山水画（水墨に淡い彩色）。絹や古い紙の質感。差し色は金と朱
- 絵の中に文字（漢字・数字・ロゴ・地名）を一切入れない
- 「三國志」シリーズなど、市販のゲームの地図や画面に似せない。オリジナルの絵にする

M1 本地図（いちばん大事）：
- 添付した下絵（map-guide.png）を「位置の設計図」として使う。正方形 1024×1024 で作る
- 下絵の海岸線・川（黄河・長江・漢水）・赤い点（都市の場所）の位置を、できるだけ変えない。絵全体を拡大・縮小・回転・ずらしもしない
- 赤い点・点線・文字は描かない。完成の絵には都市も道も描かない（ゲームが上から城の記号と道を描く）
- 陸：古い紙や絹の色（くすんだ黄土・薄い茶）に、淡い緑の平野。山は山水画風の小さな山の連なりで描く：
  ・太行山脈（晋陽と鄴・河内のあいだを南北に）・秦嶺（長安と漢中のあいだを東西に）・大巴山（漢中と梓潼・永安のあいだ）
  ・四川の盆地（成都・江州のまわりは平らで、そのまわりを山が囲む）・南嶺（長沙・零陵・桂陽と南海のあいだ）
  ・西北（武威・金城のあたり）は乾いた黄土と砂漠ぎみ・西南（建寧のあたり）は深い山と森
- 川：黄河は黄土色がかった太い流れ、長江は青緑の太い流れ、漢水はやや細く。湖として洞庭湖（江陵と長沙のあいだ）と鄱陽湖（柴桑の南東）を描く
- 海：深い藍色。波は控えめな線の模様
- 都市の点があった場所のまわり（半径30pxほど）は、山や濃い模様を置かず、明るく平らにしておく（ゲームが城の記号と白い地名を重ねるため）
- 全体はやや暗め・落ち着いた色に。上に白い文字と色つきの記号が乗っても読めるように、強いコントラストや鮮やかな色は避ける

M2 窓の地紋（つながる模様）：
- 512×512、上下左右がつながる模様（並べても継ぎ目が見えない）
- 暗い紺色（#11151f〜#1b2130）の絹の布目に、ごく薄い金色の雲文（雲の文様）。文字が乗るので、とても控えめに

では M1 から始めてください。
```

- 正方形 1024×1024 を 4列×4行のマス（1マス256×256）に分け、各マスの真ん中に1つずつ描く。マスの線は描かない。背景は透明（できなければ真っ黒の無地）

  1 大きな城（城壁と楼閣が二重。都・大都市）
  2 中くらいの城（城壁と楼閣ひとつ）
  3 小さな城（土塁と木の柵、小さな門）

  7 戦いの印（交差した剣と小さな炎。攻められている都市の目印）
  8 進軍の印（槍の穂先と矢印の形。軍が向かう方向を示す）

| K1 命令 | `sangoku/assets/cmd/<id>.png` | `--grid 4x4 --names agri,comm,def,order,recruit,train,attack,move,search,employ,reward,trade,delegate,captives,forces,officers`（id は `src/ui.js` の `data-cmd` と同じ） |

- 背景が真っ黒で返ってきたときは `--bg black`、白と灰の市松模様（透明のふり）のときは `--bg checker` をつける
- 絵が読み込めないときは今の表示（四角・文字）に戻るように作る（本体と同じ考え方）
- 城の大きさの使い分け（予定）：人口40万以上＝大、20万以上＝中、それ未満＝小、持ち主なし＝廃城。旗は勢力の色で塗り、城の右上に立てる
