# 天下三分：絵の依頼書（地図・アイコン）

ChatGPT などの画像生成に、地図とアイコンを頼むための依頼書です。
作り方は本体の `docs/ART-QUEUE.md` と同じです。ブロックごとに貼り、**1回の返事で1枚だけ**作ってもらいます。

## 使い方（持ち主向け）
1. 下の「ブロック」を1つだけ、` ``` ` の中をまるごとコピーして ChatGPT に貼る。**ブロック1だけは `sangoku/docs/map-guide.png`（下絵）も一緒に添付する**
2. ChatGPT は1回の返事で1枚だけ作る。できたら「次」と送ると、次の番号を作る
3. できた絵は **Claude Code のチャットにそのまま貼る**。番号も一言そえる（例：「M1」「C1」）。ダウンロードの期限切れを防ぐため、できたらすぐ貼るのがおすすめ
4. 上のブロックほど効果が大きい。気に入らなければ「M1をやり直し。〇〇をもっと△△に」と頼み直してよい

## 決まり（全部のブロック共通。ブロックの文にも書いてある）
- **画風**：中国の古地図と、宋〜明の山水画（水墨に淡い彩色）。絹や古い紙の質感。差し色は金と朱
- **ゲーム画面の色**：暗い紺 `#11151f`（背景）、金 `#d9b45a`（枠・見出し）、朱 `#6b2a1f`（決定ボタン）、文字は生成り `#ece4d0`
- **文字を絵に入れない**：漢字・ひらがな・数字・ロゴを描かない。都市名などはゲームが上から書く（画像生成は漢字をよく崩すため）
- **市販ゲームのまねをしない**：「三國志」シリーズなど特定のゲームの画面・地図・アイコン・顔グラフィックを参考にしたり、似せたりしない（このゲームは公開されているので、権利の線を守る）
- **勢力の色を描かない**：勢力の色（21勢力ぶん）はゲームが塗る。城は無彩色、旗は白〜灰で描き、ゲームが色を重ねる
- **小さく表示される**：アイコンはゲームで 22〜40px。細かい描き込みより、太い輪郭と2〜3色のはっきりした形を優先
