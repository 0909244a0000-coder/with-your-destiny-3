# 天下三分（三国志シミュレーション）

歴史シミュレーションの名作「三國志」シリーズ（コーエーテクモゲームス）の遊び方をお手本にした、個人で遊ぶためのファン制作ゲームです。
このフォルダだけで動く独立したゲームで、本体（With Your Destiny Ⅲ）とは関係しません。

- 遊ぶ：`sangoku/index.html` をブラウザで開く
- セーブ：ブラウザの `localStorage`（キー `wyd3-sangoku-save-v1`）。行動のたびに自動保存
- テスト：`node tools/sangoku-test.js`（データの整合・命令・25年の自動進行×3・画面の通し操作）

## 権利について（決めたこと）
- 人物・地名・出来事は史書と『三国志演義』（どちらも著作権の対象外）から使う。
- **お手本にするのは遊びのしくみだけ。** 本家の顔グラフィック・音楽・画面の絵・文章・能力値の表は使わない。能力値はこのゲーム独自に決めた（`data/officers.js`）。
- 「三國志」は商標なので、ゲームの名前には使わない。
- このリポジトリは公開されていて GitHub Pages にも出るので、厳密には「個人だけ」ではない。上の線を守って、本家の素材は入れない。

## 今できること（最小版）
- シナリオ3本（始める画面で選ぶ）：190年1月 反董卓連合（19勢力）／194年1月 群雄割拠（21勢力）／207年1月 三顧の礼（10勢力。在野の諸葛亮が新野に）。
  - 194年1月 群雄割拠（21勢力・46都市・武将約150人。うち若い武将は元服の年に登場、在野は探索で見つかる）
- 1か月が1ターン。武将1人につき毎月1回行動できる（行動済みは「済」）
- 内政：開墾（農業）・商業・城壁・治安。政治／統率／武力が高いほど上がる。金を使う
- 軍事：徴兵（魅力・金・人口・治安が下がる）・訓練（統率）・出陣・移動（輸送・空白地の占領）
- 人事：探索（在野の人物・金）・登用（在野／隣の他勢力から引き抜き）・褒美（忠誠）・売買（兵糧）
- 戦争：プレイヤーが関わる戦は **マス戦闘**（六角形のマス、`src/tactics.js`・画面 `src/battle-ui.js`・数値 `data/tactics.js`）。出陣のとき「指揮して出陣」か「自動で出陣」を選ぶ。AI に攻められたら「迎撃する（指揮）」か「委任」。AIどうしの戦は計算（`src/game.js` の autoBattle）
  - 戦場：攻めた都市から作る（森・山。山の多い州は多め、川のそばの都市は川と橋）。右に城（城壁・城門2つ・城内・本陣）
  - 兵種（出陣で武将ごとに選ぶ。最初は能力でおまかせ）：歩兵＝守り×1.2・城門攻め×1.3・弓2マス、騎兵＝移動+2・攻撃×1.2・移動してからの攻撃は突撃×1.3・森山は入りにくい・弓なし、弓兵＝弓3マスで強い・近接×0.8。守り手は能力でおまかせ（`data/tactics.js` の types）
  - 特技（`data/skills.js`。武将一覧とマス戦闘の欄に出る）：突撃（騎兵の突撃×1.5）、神弓（弓×1.5）、鉄壁（受ける損害×0.75）、火神（火計+20%・損害×1.5）、看破（受ける火計−30%）、勇将（一騎打ちで武力+10）、神速（移動+1）、名声（反撃×1.5）
  - 一騎打ちは専用の画面（2人の顔・体力の棒・1合ずつ）
  - 1日：攻め手 → 守り手の順。部隊は移動（統率80以上は1マス多い。敵の隣で止まる）してから、攻撃（隣・反撃あり）・弓（2マス・反撃なし）・火計（2マス・知力の比×地形）・一騎打ち（隣）・城門を攻める・待機
  - 城の中の守り手は城壁の高さぶん守りが固い。攻め手は城門を破らないと入れない
  - 勝ち負け：敵の全滅、総大将（出陣で1人目に選んだ武将／守り手は君主か統率の一番高い武将）が崩れる、攻め手が本陣に入る。30日で落とせなければ攻め手の負け
  - 戦の途中・月の終わりの途中でやめても、セーブから続きができる
  - AI の手（相手の番・委任・自動で出陣）は1手ずつ見せる：駒がすべって動き、道筋・狙われた駒・何が起きたかの帯が出る。速さは ゆっくり／ふつう／速い、「結果まで飛ばす」、委任中は「指揮に戻る」（`data/tactics.js` の play）
  - 演出：損害の数字（反撃は橙）、攻撃の閃光、弓の矢、火計の炎（失敗は「見破られた」）、一騎打ちの交差した武器と勝者、城門の損害と「城門突破！」、敗走・捕縛の印、日の始まりの「○日目」。自分の行動にも出る（`src/battle-ui.js` の effects）
- 捕虜：登用・解放・処断（プレイヤーが選ぶ）。AIは自動で決める
- 月の終わり：毎月 金（商業×治安）、9月に兵糧の収穫、兵糧の消費（尽きると兵が逃げる）、人口の増加、災害（疫病・洪水・蝗害）、忠誠の低い武将の出奔、1月に寿命と元服
- 君主が亡くなったら跡継ぎ（魅力＋統率が高い者）。都市がなくなると滅亡
- 計略（隣の敵へ。知力の比べ合い、成功率は窓に出る）：流言＝治安を下げる、扇動＝兵を逃がす、離間＝武将の忠誠を下げる、埋伏の毒＝自分の武将を偽って寝返らせ、その都市を攻めたとき内応して城門を開く（武将の表に「内通」）。AIの知将も流言・離間を仕掛ける（`data/rules.js` の plot・aiPlot）
- 外交（都市の命令「外交」。使者の魅力・友好度・強さの差で成功率）：贈答（友好度）、同盟12か月・停戦6か月（その間はお互いに攻められず計略もかけられない）、降伏勧告（都市2つ以下で兵がこちらの1/4以下の相手を、まるごと配下に）。AIどうしも同盟・停戦を結び、友好度の高いAIは同盟を申し入れてくる。勢力一覧に友好度と関係（`data/rules.js` の diplo）
- 委任：都市ごとにAIに任せられる
- 勝ち：全都市を取る／負け：滅亡
- 地図：ホイール・2本指で拡大（城と地名は画面で同じくらいの大きさのまま）、ドラッグで移動、右上に ＋・－・本拠・全体、左下にミニマップ（クリック・ドラッグで移動）。始めは君主の都市を中心に拡大（`data/art.js` の `view`）
