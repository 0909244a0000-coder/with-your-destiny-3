# 天下三分（三国志シミュレーション）

歴史シミュレーションの名作「三國志」シリーズ（コーエーテクモゲームス）の遊び方をお手本にした、個人で遊ぶためのファン制作ゲームです。
このフォルダだけで動く独立したゲームで、本体（With Your Destiny Ⅲ）とは関係しません。

- 遊ぶ：`sangoku/index.html` をブラウザで開く
- セーブ：ブラウザの `localStorage`（キー `wyd3-sangoku-save-v1`）。行動のたびに自動保存
- テスト：`node tools/sangoku-test.js`（データの整合・命令・25年の自動進行×3・画面の通し操作）

## 権利について（決めたこと）
- 人物・地名・出来事は史書と『三国志演義』（どちらも著作権の対象外）から使う。
- **お手本にするのは遊びのしくみだけ。** 本家の顔グラフィック・音楽・画面の絵・文章・能力値の表は使わない。能力値はこのゲーム独自に決めた（`data/officers.js`）。
- 「三國志」は商標なので、ゲームの名前には使わない。
- このリポジトリは公開されていて GitHub Pages にも出るので、厳密には「個人だけ」ではない。上の線を守って、本家の素材は入れない。

## 今できること（最小版）
- シナリオ：194年1月 群雄割拠（21勢力・46都市・武将約150人。うち若い武将は元服の年に登場、在野は探索で見つかる）
- 1か月が1ターン。武将1人につき毎月1回行動できる（行動済みは「済」）
- 内政：開墾（農業）・商業・城壁・治安。政治／統率／武力が高いほど上がる。金を使う
- 軍事：徴兵（魅力・金・人口・治安が下がる）・訓練（統率）・出陣・移動（輸送・空白地の占領）
- 人事：探索（在野の人物・金）・登用（在野／隣の他勢力から引き抜き）・褒美（忠誠）・売買（兵糧）
- 戦争：自動の合戦（最大30日）。最大5部隊、兵は統率の比で分ける。一騎打ち（武力）・火計（知力）・城壁の守備補正・訓練。落城すると武将は逃げるか捕まる。君主は逃げ場があれば必ず逃げる
- 捕虜：登用・解放・処断（プレイヤーが選ぶ）。AIは自動で決める
- 月の終わり：毎月 金（商業×治安）、9月に兵糧の収穫、兵糧の消費（尽きると兵が逃げる）、人口の増加、災害（疫病・洪水・蝗害）、忠誠の低い武将の出奔、1月に寿命と元服
- 君主が亡くなったら跡継ぎ（魅力＋統率が高い者）。都市がなくなると滅亡
- 委任：都市ごとにAIに任せられる
- 勝ち：全都市を取る／負け：滅亡

## 数値
すべて `data/rules.js`（収入・費用・戦争・AI・災害）。都市は `data/cities.js`、武将は `data/officers.js`、配置は `data/scenarios.js`。
