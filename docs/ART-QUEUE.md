# 絵の発注キュー（小分け版）

**2026-10-02：ブロック1〜7 はすべて受け取り、ゲームに入れた。新しい絵が要るときは、同じ形でブロックを足す。**

**使い方（持ち主向け）**
1. 下の「ブロック」を1つだけ、まるごとコピーして ChatGPT に貼る（ブロックは1つずつで完結している）
2. ChatGPT は **1回の返事で1枚だけ** 作る。できたら「次」と送ると、次の番号を作る
3. できた絵は **Claude Code のチャットにそのまま貼る（添付する）**。番号も一言そえる（例：「P1」）
   - ダウンロードの期限切れを防ぐため、できたらすぐ貼るのがおすすめ。スクショでも使えるが、画質は落ちる
4. ブロックが終わったら、次のブロックを貼る。どのブロックからでも始めてよい（上ほど効果が大きい）

**受け取る側（Claude Code）**：番号でファイル名と置き場所がわかる。切り取り・縮小は `tools/prepare_sprite.py`、書く場所は `docs/ART.md` の各項目。
