# With Your Destiny Ⅲ 設計図

## 一言で
人生をかけてアップデートしながら遊んでいく、オート戦闘のディアブロ。

## 決まっていること
・プレイ画面は戦闘世界を全画面表示し、HP/経験値・進行・再生速度などの必要な情報だけ常設。キャラ/スキル/リザルトは開閉式の情報窓、装備/持ち物は専用の大きなウィンドウで操作（2026-10-06 UI刷新）
・PC専用、ブラウザで遊ぶ
・世界観にしばりはない。いまは敵・ボス・エリアがタントラ風、主人公の側（職業・スキル・装備）が西洋のダークファンタジー。新しく足すものは、タントラ風でもそれ以外でもよい（おもしろさを優先）
・遊びの中心はディアブロと同じ：敵を倒す → 装備が落ちる → ビルドを組む → もっと強い敵へ
・戦闘はオート。キャラはマップ上を自動で動いて戦い、プレイヤーは見ているだけ
・プレイヤーがやることは、装備とスキルの組み合わせを選ぶこと
・職業/ビルドの不均等さと、強い組み合わせの発見を歓迎する。均等化を目的に一律調整しない（2026-10-05 ユーザー方針）
・視点は2Dの見下ろし
・通常戦闘のカメラはPC／横持ちで1.0／1.2／1.4倍を選択（既定1.2）。スマホ縦持ちは既存の追従倍率を使用。カメラは描画だけに作用し、射程や当たり判定は変わらない。既存の状態効果と残り秒数・召喚数をHP欄の上に表示し、敵と召喚の拘束は頭上にも表示（2026-10-08）

## 最小版で作るもの
・職業7つ（バーバリアン、ソーサレス、ネクロマンサー＝骸骨の戦士と魔術師を呼ぶ、パラディン＝オーラ（ONのあいだずっと効くスキル）を持つ、アサシン＝地面に置く罠と影の戦士、ドルイド＝熊・狼への変身と狼の群れ、冥爆術師＝時限・追尾・地雷・連鎖起爆）。キャラごとにセーブは別々で、上のバーで切り替え（data/classes.js、追加職業は data/bombmancer.js）
・装備ドロップ（性能ランダム、レア度で色分け）。部位は9つ（武器・頭・胴・手・足・指輪・盾・首飾り・帯）
・装備の特殊効果（レア度が高いほど多く付く。種類・数値・出やすさは data/effects.js）
・精鋭（エリート）敵：ときどき能力つきの強い敵が出て、装備を多く落とす。能力は10種類（疾風・金剛・剛力・吸血・業火・眷属使い・氷結・爆砕・守護・瞬身。data/elites.js）
・エリア6つ（4つ目「奈落の大聖堂」、5つ目「凍てつく深淵」、6つ目「業火の玉座」。6エリアに専用の景色を追加）。それぞれ地下1〜3階とボスの間。決まった数を倒すと次の階へ降り、一番奥のボスを倒すと次のエリアへ行ける（data/areas.js）
・各職業スキル9つ。同時にONにできるのは3つまでで、組み合わせがビルドになる（data/skills.js）。セーブや構成の読み込みで上限を超えていたら、おまかせの順（autoBuild→skillOrder）で先のものだけ残してONにする（src/save.js の limitSkills、2026-10-08）
・スキルの型（ルーン）：各スキルに3つの型があり、スキルLv2・4・6で解放。1つ選ぶとスキルの性質が変わる（data/runes.js）
・セット装備（6セット。うち3つは職業専用）：同じセットを2つ・4つ身につけるとボーナス。ボスと精鋭がまれに落とす（data/sets.js）
・終わりのない試練：クリア後に挑める。制限時間内に決まった数を倒すと守護者が出て、倒せば次の段階へ（上限なし）。自己ベストを記録（data/trial.js）
・挑戦の記録：試練・日替わり・地図・奈落の双王に成功すると、日時・段階・かかった時間・季節を残す（最近30件と種類ごとの最高）。「図鑑と記録」で見られる
・熟練：レベルを上げて OFF にしたスキルは、種類に応じた能力（スキル威力・会心率・防御・HP・攻撃速度など）がレベルぶん上がる（data/mastery.js）
・狙って周回：ユニーク・セットはそれぞれ「よく落ちるエリア」があり、そのエリアのボス・精鋭がよく落とす。図鑑はエリアごとの表になっている（data/uniques.js・data/sets.js の home）
・図鑑と記録：見つけたユニーク・セット装備の図鑑、倒した数などの記録、実績（達成で素材）。上のバーの「図鑑と記録」（data/records.js）
・日替わりの試練：クリア後、1日1回。日付で決まる条件（敵のHPが高い・時間が短い など2つ）で試練に挑み、成功で素材・ユニーク・宝石。連続で成功すると素材が増える（data/daily.js）
・ボス専用の技：羅刹王＝分身（うすい姿・倒しても何も落とさない）、阿修羅王＝突進（予告の線のあと走り抜ける。主人公は横へよける）、水牛魔＝毒の沼（主人公は沼から出る）、大司教＝弾幕（data/enemies.js の clone・charge・pools・barrage）
・ボスの救済：ボスに倒されるたびに、そのボスのHPと攻撃力が5%ずつ下がる（最大-30%。倒すと元にもどる。data/areas.js の boss.easePerDeath）
・宝物ゴブリン：まれに出て逃げ回る金色の敵。主人公は優先して追いかける。14秒以内に倒すと装備6個・素材・宝石（data/elites.js の goblin）
・ボスの怒り：ボス（と試練の守護者）はHPが半分を切ると1回だけ怒り、速く・強くなって手下を2体呼ぶ（data/areas.js の boss.enrage）
・星座（Grim Dawn）：上のバーの「星座」。レベル・ボス・試練・地図の記録で信仰ポイントがたまり、星座を埋める。星座には「縁（戦・魔・命）」が必要なものがあり、上の星座は固有能力つき。外すとポイントはもどる（data/devotion.js）
・傭兵（Diablo 2）：「やり込み」→「傭兵」。レベル5から素材で1人雇える（槍兵・弓兵・魔術師）。強さは主人公の能力に合わせて変わり、倒れても12秒で戻る。雇っているあいだ「加護」（槍兵＝防御と吸血、弓兵＝会心率、魔術師＝スキル威力）。素材で位を5まで上げるとHPと攻撃力がふえる（data/mercenary.js）
・伝説の宝石（Diablo 3）：「やり込み」→「伝説の宝石」。試練（日替わり・地図・双王もふくむ）に成功すると、まだ持っていない宝石が手に入ることがある（最初の1つは必ず）。3つまで身につけられ、成功するたびにつけている宝石のランクが自動で上がる（高い段階ほど上がりやすい）。6種類：動けない敵へのダメージ、精鋭・ボスを倒した後のダメージ、距離でダメージ、当てるたびに攻撃速度、最大HP、吸血（data/legendaryGems.js）
・祠とパイロン（Diablo 2・3）：戦っていると60〜100秒ごとに地面に祠が出る。主人公が自動で触りに行き、触ると25〜40秒、強い効果がつく（力＝攻撃力1.8倍、疾風＝攻撃速度と移動速度1.5倍、雷＝近くの敵に雷、守り＝防御2倍とHP回復、幸運＝レア発見+100%と経験値1.5倍）。触らないと40秒で消える（data/shrines.js）
・キャダラの賭け（Diablo 3）：持ち物の操作欄、または「拾う・装備」→「キャダラの賭け」。レベル10から。部位をタップで1個、長押しで同じ部位を連続購入（指を離す・移動・画面を閉じる・素材不足・180枠で停止）。素材を払って部位を選ぶと、その部位の装備がランダムで1つ持ち物に入る（レア70%・レジェンド18%・ユニーク6%・セット6%。その部位にユニーク・セットがなければレジェンド）。アイテムレベルは行ったことのある一番奥のエリアと最高危険度で決まる（data/gamble.js）
・裂け目（Path of Exile の Breach）：ふつうの冒険中（試練とボスの間以外）に、3〜5分ごとに近くに裂け目が開く。20秒間、紫色の異界の敵（HP・攻撃は弱め）が次々に出て、倒すと経験値が多く、装備もよく落ちる。閉じると残りは消え、倒した数に応じて装備（レア度高め）と素材の宝箱。開いている間は次の階へ降りない（data/breach.js）
・賞金首の依頼（Diablo 3 の Bounties）：「やり込み」→「賞金首の依頼」。いつも3つの依頼（エリアで敵／精鋭を倒す、ボスを倒す、祠・裂け目・宝物ゴブリン）があり、遊んでいるだけで進む。達成すると素材と装備2個（レア以上）。素材20で取り替えられる（data/bounties.js）
・戦利品フィルター：上のバーの「フィルター」。部位ごとに「このレア度から拾う」を決める。今より強いものは拾う設定も（data/crafting.js の filterLevels）
・季節のルール（D4 シーズン・PoE リーグ風）：上のバーの「季節」で1つ選ぶ。精鋭・黄金・血・輝石・嵐（むずかしい）の5つ。遊び方が変わり、ごほうびが増える（data/seasons.js）
・太古・始原（Diablo 3）：レジェンド・ユニーク・セットが10%で「太古」（能力1.3倍）、1%で「始原」（1.6倍）になって落ちる（data/items.js の ancient）
・鍛造（Last Epoch）：装備の窓の「鍛造…」。装備ごとの「鍛造の余地」を使い、能力1つを元の値の8%ずつ上げる・新しい能力を足す。余地がなくなるまで。12%で余地が減らない（data/crafting.js の forge）
・奈落の双王（Diablo の Uber ボス風）：危険度5以上のボス・試練や地図の守護者がまれに「奈落の鍵」を落とす。3つで、強くなった羅刹王と阿修羅王に同時に挑める。勝つとユニーク2個（ここでしか出ないユニーク「奈落の心臓」「双王の冠」もある）・素材・宝石（data/uber.js）
・地図（Path of Exile）：クリア後に地図（段階1〜16、条件0〜4つ）が落ちる。使うと条件つきの試練に挑み、守護者を倒すと次の地図（ときどき1つ上の段階）が落ちる。条件が多いほどごほうびの量が増える。素材で「レア」（条件3〜4つ）にできる（data/maps.js）
・ルーンスキル（2026-10-06再設計）：装備から独立した専用4枠目。欠片3個（初回無料1回）または奈落の変質石1個で、属性6×動き5×追加効果5の150通りから完成スキルを等確率抽選。変質石1個で選んだ1箇所だけ再抽選し、結果を見て採用/維持。data/runeSkills.js。
・カナイの箱（Diablo 3）：ユニークを分解して固有能力を覚え、武器・防具・指輪の3つの枠に入れると装備とは別に効く（data/cube.js）
・振り直し：スキル欄の「振り直し」。素材を使って、スキルポイントを全部もどす（スキルの型も外れる）。修練（秘技・能力の盤面）はそのまま（data/crafting.js の respec）
・装備のロック：Ctrl＋クリックでロック。ロックした装備は捨てられず、まとめて捨てる・自動装備の対象にもならない
・戦闘リザルト：PC右下（折りたたみ）、スマホは戦闘の下。通常攻撃・スキル・装備効果・召喚・傭兵・祠の与ダメージ、割合、DPS、命中、実測会心率、発動数、自分の被ダメージ・回復・撃破・倒れた回数。全体／直近10秒、計測停止・再開・リセット。敵HP超過・無効化は除外、補助効果は元の攻撃に含む。記録はセーブしない（data/results.js・src/results.js）
・スキル演出：防御・強化・召喚・罠・オーラは、煙・炎・光の画像と拡大・上昇・減衰で見せる。追加した幾何学的な紋章は撤去。罠の射撃は炎・稲妻・影の画像。追加の描画は戦闘乱数を使わない（data/vfx.js）
・開始地点：初回・再読み込み・職業切替後は野営地。保存したエリア・階を出発先として保持し、「戦場へ」で再開。拠点では敵が出ずHP全快、リザルトの時間も進まない
・秒間ダメージ：キャラ欄に直近10秒の平均（ビルドの強さの目安。data/items.js の combat.dpsWindow）
・ビルドの保存：装備欄の下で4つまで。装備・使うスキル・スキルの型・カナイの箱の枠をまとめて保存し、ワンクリックで切り替え（倉庫にある装備も持ってくる）
・上のバー：キャラ・エリア・危険度・試練・速度・季節はいつも見える。ほかは「拾う・装備」「やり込み」「設定」のメニューにまとめた
・大事な知らせ：ユニーク・セット・太古の装備、実績、鍵、ゴブリン、ボスの怒り、試練・地図などの成功は画面の真ん中に大きく出る（data/map.js の notice）
・一時停止：上のバーの「停止」かスペースキー。1・2・4キーで速度
・装備の比べやすさ：持ち物で、今より強い装備に緑の「▲」。説明に「総合の目安 ▲+◯%」（自動装備と同じ点数）
・自動装備：上のバーでON。拾った装備が今より強ければ自動で着替える（ユニーク・セット・強化・宝石・鍛造済み・保存ビルド用は外さない。空の土台は持ち物に戻せるので自動交換可。点数の重みは data/items.js の autoEquip）
・装備の強化：素材で装備を +1〜+10 に強化（+1 ごとに能力8%アップ）。捨てると使った素材の半分がもどる。「全て捨てる」は確認後に強化・宝石つきも分解する（ロックは除外）（data/crafting.js の enhance）
・ソケットと宝石：装備にソケットがつくことがあり、宝石（4種類×5段階）をはめると能力が上がる。同じ宝石3つと素材で1つ上の段階に。装備を捨てると宝石は手元にもどる（data/gems.js）
・宝石の画面（2026-10-09）：宝石は持ち物とは別の窓（下のアイコン「Gems」、スマホは「その他」→「宝石」）。手元の宝石とはめている宝石の一覧。種類（ふつう・混沌・神）で絞る、能力・名前で検索（空白で複数）、並べ替え（段階・種類／新しい順／能力の数／検索した能力の強さ＝能力の幅のどのあたりか）。「はめる」→ はめ先（身につけた装備・持ち物で空きのあるもの）を選ぶ。はめている宝石は1つずつ「外す」（無料・何度でも）。段階の合成と宝石合成もここ。再合成：手元の混沌の宝石（神もふくむ）を5個選んで新しい混沌の宝石1個に作り直す（割は悪い。使わない宝石をためないため。「見えている混沌の宝石を選ぶ」で絞り込み・検索の結果から上から5個。data/gems.js の fusion.refuse）。かばんの宝石の欄・宝石を選んで装備をクリックする操作・宝石を外すモードはなくした（src/gemvault.js）
・宝石合成（2026-10-09）：宝石の欄の「宝石合成」で、種類も段階も混ぜて王者10個ぶん（欠けた=1、1段ごとに3倍、王者=81 → 810）を使い、「混沌の宝石」を1つ作る。段階の低い宝石から使う（ルーンは使わない）。能力の数（1〜4）・種類・数値はすべてランダムで、既存の宝石にない特殊効果（吸血・刻の加速・会心ダメージ・雷鳴など）も出る。どの部位にはめても同じ能力。特殊効果は装備の特殊効果と合計し、上限（cap）もそのまま。能力は宝石の名前に書きこむ（`fused:attack=24,fx.lifesteal=3.5`）ので、セーブ・アリーナもそのまま動く（data/gems.js の fusion、src/gems.js）
  ・極レアと神（2026-10-09 追加指示）：当たりは種類を多く（全28種）し、極レア・神は出にくく（1回の合成で、神 約1%・狙った神 約0.2%・割合 約8%・固有能力 約7%）。理想の組み合わせは運か大量の合成が必要。
  ・極レア（はめる数に制限なし）：割合（攻撃力%・防御力%・最大HP%・全ステータス%。上限なし）と固有能力（屍爆・弾はじき・精鋭特効・隠者。ユニークと同じしくみで、同じ固有能力は1つだけ効く。装備・星座・箱のほうが優先）。
  ・神の能力（通常攻撃で発動）：雷霆（確率でスタン。ボスは短い・対人は拘束の規則どおり）・残響（もう1回当たる）・断罪（低HPの敵を確率で即死。ボス・対人の相手は除く）・震撃（衝撃波）・烙印（当てた敵の被ダメージ増）。宝石1つに1つまで、身につけた装備には1つまでしかはめられない。持ち物の装備から着替えて2つになったときは、最初の1つ（部位の順）だけ効く。
  ・一度だけの巻き戻し（2026-10-09）：神が出すぎ・強すぎたため、それまでの合成をなかったことにする。旧セーブを開いたとき、混沌の宝石（持ち物・はめた分）をすべて外し、1つにつき王者の宝石10個（種類はランダム）を返す（実際に使った宝石は記録していないため、同じ量で返す）。フラグ `fusionRollback1` で一度だけ。新しいセーブは対象外（data/gems.js の fusion.rollback）
・セーブのバックアップ：ファイルに書き出す・読み込む。壊れたら自動の控えから戻す
・分解とクラフト：装備を捨てると素材「魂の欠片」になり、素材で特殊効果をつけ直せる（data/crafting.js）
・遠くから弾を撃つ敵（各エリアに1種類。data/enemies.js の ranged）
・ユニーク装備（16種類。職業専用のスキル強化＝skillBoost もある。味方を呼ぶもの＝periodicSummon もある。職業専用のものは classOnly）：名前と固有能力（スキルの動きを変える）が決まった装備。ボスと精鋭がまれに落とす（data/uniques.js）
・危険度の「自動」：解放されたら自動で上げ、何度も倒れたら1つ下げる（data/enemies.js の difficulty）
・自動分解（選んだレア度以下は拾わずに素材にする）、装備の効果のまとめ表示、倉庫廃止（持ち物180個）、持ち物がいっぱいなら弱い装備と入れ替え（「拾う・装備」でON・OFF）
