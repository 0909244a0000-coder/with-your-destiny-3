# With Your Destiny Ⅲ 設計図

## 一言で
人生をかけてアップデートしながら遊んでいく、オート戦闘のディアブロ。

## 決まっていること
・PC専用、ブラウザで遊ぶ
・世界観にしばりはない。いまは敵・ボス・エリアがタントラ風、主人公の側（職業・スキル・装備）が西洋のダークファンタジー。新しく足すものは、タントラ風でもそれ以外でもよい（おもしろさを優先）
・遊びの中心はディアブロと同じ：敵を倒す → 装備が落ちる → ビルドを組む → もっと強い敵へ
・戦闘はオート。キャラはマップ上を自動で動いて戦い、プレイヤーは見ているだけ
・プレイヤーがやることは、装備とスキルの組み合わせを選ぶこと
・視点は2Dの見下ろし

## 最小版で作るもの
・職業3つ（バーバリアン、ソーサレス、ネクロマンサー）。キャラごとにセーブは別々で、上のバーで切り替え（data/classes.js）
・装備ドロップ（性能ランダム、レア度で色分け）
・装備の特殊効果（レア度が高いほど多く付く。種類・数値・出やすさは data/effects.js）
・精鋭（エリート）敵：ときどき能力つきの強い敵が出て、装備を多く落とす。能力は10種類（疾風・金剛・剛力・吸血・業火・眷属使い・氷結・爆砕・守護・瞬身。data/elites.js）
・エリア3つ。それぞれ地下1〜3階とボスの間。決まった数を倒すと次の階へ降り、一番奥のボスを倒すと次のエリアへ行ける（data/areas.js）
・スキル6つ。同時にONにできるのは3つまでで、組み合わせがビルドになる（data/skills.js）
・スキルの型（ルーン）：各スキルに3つの型があり、スキルLv2・4・6で解放。1つ選ぶとスキルの性質が変わる（data/runes.js）
・セット装備：同じセットを2つ・4つ身につけるとボーナス。ボスと精鋭がまれに落とす（data/sets.js）
・終わりのない試練：クリア後に挑める。制限時間内に決まった数を倒すと守護者が出て、倒せば次の段階へ（上限なし）。自己ベストを記録（data/trial.js）
・図鑑と記録：見つけたユニーク・セット装備の図鑑、倒した数などの記録、実績（達成で素材）。上のバーの「図鑑と記録」（data/records.js）
・日替わりの試練：クリア後、1日1回。日付で決まる条件（敵のHPが高い・時間が短い など2つ）で試練に挑み、成功で素材・ユニーク・宝石。連続で成功すると素材が増える（data/daily.js）
・ボスの怒り：ボス（と試練の守護者）はHPが半分を切ると1回だけ怒り、速く・強くなって手下を2体呼ぶ（data/areas.js の boss.enrage）
・装備の比べやすさ：持ち物で、今より強い装備に緑の「▲」。説明に「総合の目安 ▲+◯%」（自動装備と同じ点数）
・自動装備：上のバーでON。拾った装備が今より強ければ自動で着替える（ユニーク・セット・強化や宝石つきは外さない。点数の重みは data/items.js の autoEquip）
・装備の強化：素材で装備を +1〜+10 に強化（+1 ごとに能力8%アップ）。捨てると使った素材の半分がもどる。強化・宝石つきの装備は「まとめて捨てる」の対象外（data/crafting.js の enhance）
・ソケットと宝石：装備にソケットがつくことがあり、宝石（4種類×5段階）をはめると能力が上がる。同じ宝石3つと素材で1つ上の段階に。装備を捨てると宝石は手元にもどる（data/gems.js）
・セーブのバックアップ：ファイルに書き出す・読み込む。壊れたら自動の控えから戻す
・分解とクラフト：装備を捨てると素材「魂の欠片」になり、素材で特殊効果をつけ直せる（data/crafting.js）
・遠くから弾を撃つ敵（各エリアに1種類。data/enemies.js の ranged）
・ユニーク装備：名前と固有能力（スキルの動きを変える）が決まった装備。ボスと精鋭がまれに落とす（data/uniques.js）
・危険度の「自動」：解放されたら自動で上げ、何度も倒れたら1つ下げる（data/enemies.js の difficulty）
・自動分解（選んだレア度以下は拾わずに素材にする）、装備の効果のまとめ表示、倉庫（持ち物と別に30個）
・放置中の進行：閉じていた時間（タブを裏にしていた時間も）、遊んでいるときの稼ぎの半分ぶん経験値・素材・宝石をもらえる（data/offline.js）
・目標：3つのエリアのボスを倒すとクリア。そのあとは危険度を上げていく。遊び方の説明と、エリアに入ったときの一言（data/story.js）
・修練：レベル上限（50）のあとの経験値で修練レベルが上がり、ポイントで能力を少しずつ上げられる（data/player.js の paragon）
・見た目と音：火花・血しぶき・画面の揺れ・レア装備の光の柱（data/fx.js）、絵の動き（data/anim.js）、ディアブロ風のパネル、効果音（data/sound.js）
・持ち物と装備の画面、レベルアップ

## 作り方のルール
・数値（敵の強さ・装備の性能など）は data/ にまとめる
・絵は最初は丸や四角でいい。あとでGPTのイラストに差し替える
・1回の作業は1つの目的だけ
