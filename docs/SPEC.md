# With Your Destiny Ⅲ 設計図

## 一言で
人生をかけてアップデートしながら遊んでいく、オート戦闘のディアブロ。

## 決まっていること
・PC専用、ブラウザで遊ぶ
・世界観にしばりはない。いまは敵・ボス・エリアがタントラ風、主人公の側（職業・スキル・装備）が西洋のダークファンタジー。新しく足すものは、タントラ風でもそれ以外でもよい（おもしろさを優先）
・遊びの中心はディアブロと同じ：敵を倒す → 装備が落ちる → ビルドを組む → もっと強い敵へ
・戦闘はオート。キャラはマップ上を自動で動いて戦い、プレイヤーは見ているだけ
・プレイヤーがやることは、装備とスキルの組み合わせを選ぶこと
・視点は2Dの見下ろし

## 最小版で作るもの
・職業4つ（バーバリアン、ソーサレス、ネクロマンサー＝骸骨の戦士と魔術師を呼ぶ、パラディン＝オーラ（ONのあいだずっと効くスキル）を持つ）。キャラごとにセーブは別々で、上のバーで切り替え（data/classes.js）
・装備ドロップ（性能ランダム、レア度で色分け）。部位は9つ（武器・頭・胴・手・足・指輪・盾・首飾り・帯）
・装備の特殊効果（レア度が高いほど多く付く。種類・数値・出やすさは data/effects.js）
・精鋭（エリート）敵：ときどき能力つきの強い敵が出て、装備を多く落とす。能力は10種類（疾風・金剛・剛力・吸血・業火・眷属使い・氷結・爆砕・守護・瞬身。data/elites.js）
・エリア5つ（4つ目「奈落の大聖堂」、5つ目「凍てつく深淵」。この2つの絵は仮）。それぞれ地下1〜3階とボスの間。決まった数を倒すと次の階へ降り、一番奥のボスを倒すと次のエリアへ行ける（data/areas.js）
・スキル6つ。同時にONにできるのは3つまでで、組み合わせがビルドになる（data/skills.js）
・スキルの型（ルーン）：各スキルに3つの型があり、スキルLv2・4・6で解放。1つ選ぶとスキルの性質が変わる（data/runes.js）
・セット装備（6セット。うち3つは職業専用）：同じセットを2つ・4つ身につけるとボーナス。ボスと精鋭がまれに落とす（data/sets.js）
・終わりのない試練：クリア後に挑める。制限時間内に決まった数を倒すと守護者が出て、倒せば次の段階へ（上限なし）。自己ベストを記録（data/trial.js）
・挑戦の記録：試練・日替わり・地図・奈落の双王に成功すると、日時・段階・かかった時間・季節を残す（最近30件と種類ごとの最高）。「図鑑と記録」で見られる
・図鑑と記録：見つけたユニーク・セット装備の図鑑、倒した数などの記録、実績（達成で素材）。上のバーの「図鑑と記録」（data/records.js）
・日替わりの試練：クリア後、1日1回。日付で決まる条件（敵のHPが高い・時間が短い など2つ）で試練に挑み、成功で素材・ユニーク・宝石。連続で成功すると素材が増える（data/daily.js）
・ボス専用の技：羅刹王＝分身（うすい姿・倒しても何も落とさない）、阿修羅王＝突進（予告の線のあと走り抜ける。主人公は横へよける）、水牛魔＝毒の沼（主人公は沼から出る）、大司教＝弾幕（data/enemies.js の clone・charge・pools・barrage）
・ボスの救済：ボスに倒されるたびに、そのボスのHPと攻撃力が5%ずつ下がる（最大-30%。倒すと元にもどる。data/areas.js の boss.easePerDeath）
・宝物ゴブリン：まれに出て逃げ回る金色の敵。主人公は優先して追いかける。14秒以内に倒すと装備6個・素材・宝石（data/elites.js の goblin）
・ボスの怒り：ボス（と試練の守護者）はHPが半分を切ると1回だけ怒り、速く・強くなって手下を2体呼ぶ（data/areas.js の boss.enrage）
・星座（Grim Dawn）：上のバーの「星座」。レベル・ボス・試練・地図の記録で信仰ポイントがたまり、星座を埋める。星座には「縁（戦・魔・命）」が必要なものがあり、上の星座は固有能力つき。外すとポイントはもどる（data/devotion.js）
・戦利品フィルター：上のバーの「フィルター」。部位ごとに「このレア度から拾う」を決める。今より強いもの・ルーンワードの土台は拾う設定も（data/crafting.js の filterLevels）
・季節のルール（D4 シーズン・PoE リーグ風）：上のバーの「季節」で1つ選ぶ。精鋭・黄金・血・輝石・嵐（むずかしい）の5つ。遊び方が変わり、ごほうびが増える（data/seasons.js）
・太古・始原（Diablo 3）：レジェンド・ユニーク・セットが10%で「太古」（能力1.3倍）、1%で「始原」（1.6倍）になって落ちる（data/items.js の ancient）
・鍛造（Last Epoch）：「鍛造モード」で装備をクリック。装備ごとの「鍛造の余地」を使い、能力1つを元の値の8%ずつ上げる・新しい能力を足す。余地がなくなるまで。12%で余地が減らない（data/crafting.js の forge）
・奈落の双王（Diablo の Uber ボス風）：危険度5以上のボス・試練や地図の守護者がまれに「奈落の鍵」を落とす。3つで、強くなった羅刹王と阿修羅王に同時に挑める。勝つとユニーク2個（ここでしか出ないユニーク「奈落の心臓」「双王の冠」もある）・素材・宝石（data/uber.js）
・地図（Path of Exile）：クリア後に地図（段階1〜16、条件0〜4つ）が落ちる。使うと条件つきの試練に挑み、守護者を倒すと次の地図（ときどき1つ上の段階）が落ちる。条件が多いほどごほうびの量が増える。素材で「レア」（条件3〜4つ）にできる（data/maps.js）
・ルーンとルーンワード（Diablo 2）：ルーン12種類（エル〜ベル）。ルーン3つと素材で1つ上へ。ノーマル装備のソケットを決まった順番でうめるとルーンワード（8種類。図鑑にレシピ一覧）。ソケット2つ以上のノーマル装備は自動分解しない（data/gems.js の runes・runewords）
・カナイの箱（Diablo 3）：ユニークを分解して固有能力を覚え、武器・防具・指輪の3つの枠に入れると装備とは別に効く（data/cube.js）
・振り直し：スキル欄の「振り直し」。素材を使って、スキルと修練のポイントを全部もどす（data/crafting.js の respec）
・装備のロック：Ctrl＋クリックでロック。ロックした装備は捨てられず、まとめて捨てる・自動装備の対象にもならない
・秒間ダメージ：キャラ欄に直近10秒の平均（ビルドの強さの目安。data/items.js の combat.dpsWindow）
・ビルドの保存：装備欄の下で4つまで。装備・使うスキル・スキルの型・カナイの箱の枠をまとめて保存し、ワンクリックで切り替え（倉庫にある装備も持ってくる）
・上のバー：キャラ・エリア・危険度・試練・速度・季節はいつも見える。ほかは「拾う・装備」「やり込み」「設定」のメニューにまとめた
・大事な知らせ：ユニーク・セット・太古の装備、実績、鍵、ゴブリン、ボスの怒り、試練・地図などの成功は画面の真ん中に大きく出る（data/map.js の notice）
・一時停止：上のバーの「停止」かスペースキー。1・2・4キーで速度
・装備の比べやすさ：持ち物で、今より強い装備に緑の「▲」。説明に「総合の目安 ▲+◯%」（自動装備と同じ点数）
・自動装備：上のバーでON。拾った装備が今より強ければ自動で着替える（ユニーク・セット・強化や宝石つきは外さない。点数の重みは data/items.js の autoEquip）
・装備の強化：素材で装備を +1〜+10 に強化（+1 ごとに能力8%アップ）。捨てると使った素材の半分がもどる。強化・宝石つきの装備は「まとめて捨てる」の対象外（data/crafting.js の enhance）
・ソケットと宝石：装備にソケットがつくことがあり、宝石（4種類×5段階）をはめると能力が上がる。同じ宝石3つと素材で1つ上の段階に。装備を捨てると宝石は手元にもどる（data/gems.js）
・セーブのバックアップ：ファイルに書き出す・読み込む。壊れたら自動の控えから戻す
・分解とクラフト：装備を捨てると素材「魂の欠片」になり、素材で特殊効果をつけ直せる（data/crafting.js）
・遠くから弾を撃つ敵（各エリアに1種類。data/enemies.js の ranged）
・ユニーク装備（16種類。職業専用のスキル強化＝skillBoost もある。味方を呼ぶもの＝periodicSummon もある。職業専用のものは classOnly）：名前と固有能力（スキルの動きを変える）が決まった装備。ボスと精鋭がまれに落とす（data/uniques.js）
・危険度の「自動」：解放されたら自動で上げ、何度も倒れたら1つ下げる（data/enemies.js の difficulty）
・自動分解（選んだレア度以下は拾わずに素材にする）、装備の効果のまとめ表示、倉庫（持ち物と別に30個）
・放置中の進行：閉じていた時間（タブを裏にしていた時間も）、遊んでいるときの稼ぎの半分ぶん経験値・素材・宝石をもらえる（data/offline.js）
・目標：5つのエリアのボスを倒すとクリア（最後のボス「氷獄の竜王」は突進と氷のつぶて）。そのあとは危険度を上げていく。遊び方の説明と、エリアに入ったときの一言（data/story.js）
・修練とパラゴンボード（Diablo 4）：レベル上限（50）のあとの経験値で修練ポイントがたまり、11×11の盤面のマスを取っていく（となりのマスだけ取れる）。ふつう・マジック・レア・伝説のマスがあり、伝説は固有能力つき。前の振り方のセーブは、読み込むとポイントがもどる（data/player.js の paragon.board）
・BGM：ブラウザで作る雰囲気の曲。エリアごと・ボス戦・試練で曲が変わる。「設定」→「音楽」でON/OFF（data/music.js）
・見た目と音：火花・血しぶき・画面の揺れ・レア装備の光の柱（data/fx.js）、絵の動き（data/anim.js）、ディアブロ風のパネル、効果音（data/sound.js）
・持ち物と装備の画面、レベルアップ

## 作り方のルール
・数値（敵の強さ・装備の性能など）は data/ にまとめる
・絵は最初は丸や四角でいい。あとでGPTのイラストに差し替える
・1回の作業は1つの目的だけ
