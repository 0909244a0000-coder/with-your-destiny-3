# Status・宝石窓の修正

## 観察と対応
- 1920×1080 の提供画面で、宝石窓の右側の工房が切れ、横スクロールが発生。画面幅が狭くなる場合の工房の配置を下段へ切り替え、カードの文字とボタンを幅内に収める。
- Statusには装備欄の下にカナイの箱があるが、`#bag[data-view="status"] #cube-panel` のCSSで常に非表示だった。`hidden` の状態にだけ従って表示し、既存の3枠の `select` と変更イベントを再利用する。
- 装備側にユニークがあるのに発見記録が古いセーブでも入口を表示する。
- 箱と宝石工房用の絵を追加。画像生成で透過のダークファンタジー素材を作り、箱は320×292、坩堝は320×316のWebPへ縮小した。パネルの説明と操作ラベルも実際の取り出し・付け替え手順に合わせた。

## 検証
- `node --check src/ui.js` と `node --check src/gemvault.js`、`git diff --check` は成功。
- `node tools/run-tests.js` は33件すべてPlaywright用Chromiumが未配置のためブラウザ起動前に失敗。例：`/root/.cache/ms-playwright/chromium_headless_shell-1234/...` が存在しない。テストの判定結果ではない。
