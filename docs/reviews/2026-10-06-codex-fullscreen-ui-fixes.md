# 全画面UIの操作と重なりを修正

PR #121の続き。旧チャットのエラー後も変更はGitHubに残っており、コミット `1c2f0a09017997cfaab19ddd75f5cc34da0abb53` から再開した。

## 実際に見つかった問題
- 1363×936の試遊で、上部HUDは高さ130px・下端140pxだったのに、人物/装備/DPSボタンは108pxから始まり、HUDの下へ隠れていた。
- 装備ウィンドウはz-index 25、賭け/鍛造/アイテム操作のモーダルは20のため、装備から開く子窓が背面になっていた。
- スマホ縦のDPSボタンはCSSで非表示になっていた。
- 子窓のEscapeが背後の人物/装備まで閉じる経路があった。
- 16:9のPCで戦闘キャンバスをcover拡大すると、上下の戦場・スキル表示が切れる。

## 修正
- ResizeObserverでHUDと操作列の実寸を反映。画面サイズ・解放された操作・折り返しに合わせ、操作ボタンと現在地を下へ配置。毎フレームの計測はしない。
- スマホ縦でもDPSボタンを表示し、折り返した操作列の高さに合わせてHP/経験値と冒険ログを持ち上げる。
- 子モーダル30、装備25、ツールチップ35として階層を整理。装備の固定見出しと移動タブも実際の高さに合わせる。
- 子窓があるとき本編のショートカットを通さず、Escapeは子窓を優先。ルーンを閉じても人物は残す。アイテム操作のEscapeも追加。人物/装備の開閉時にフォーカスを移す。
- キャンバスはcontainで全視野を維持。戦場は画面いっぱいの領域を使うが、元の960×600と縦横比が違う画面では余白ができる。戦闘座標や描画解像度は維持。
