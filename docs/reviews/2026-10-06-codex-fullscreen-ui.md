# 全画面HUDと装備ウィンドウの刷新

依頼：戦闘を全画面にし、リアルタイムに不要な情報は開閉窓へ移す。窓/装備/UIデザインもまとめて刷新。参考画像はMMORPGの全画面HUD配置の手がかりとして使い、画面レイアウトと絵柄はWYD3向けに再設計。

## 変更
- ゲームの戦闘キャンバスを画面全体に拡大。HUDはクラス/エリア/危険度/試練/速度、HP/経験値/DPS、現在地とフロア、ミュート/拠点移動/装備などを必要な場所に重ねる。
- キャラ能力・スキル・リザルトを右側の開閉ドロワーに集約。背景クリックまたはEscapeで閉じ、操作中もゲームを止めない。
- 冒険ログを折りたたみ式へ。装備/持ち物を全面ウィンドウにし、職業の肖像付き装備概要、9スロット、拡張したインベントリ/倉庫一覧、統一された暗鉄と金の窓枠を用意。
- PCと横持ち画面では戦場を最大化、スマホ縦持ちは横方向を切らずキャンバス全体を見せる。固定座標の戦闘ロジックとセーブ構造は維持。
- `assets/ui/hud-crest.png` を新規作成しタイトルの紋章に追加。組み込み画像生成ツールで生成、256px透過PNG。

## 確認
- `node --check src/ui.js`、`git diff --check` 成功。
- HTMLを読み、ID重複なし（196 ID）。既存DOM IDを保持してHUD/装備画面の位置を移動。
- この実行環境にPlaywright Chromium実行ファイルがなく、実ブラウザのレイアウト/操作試験と実機スマホ確認は未実施。試遊時は特にPC全画面・390px縦・横向き、ドロワー開閉、装備/持ち物のスクロールを確認する。
- ゲーム描画解像度は960×600のままCSSで拡大するため、CPU/GPUの描画負荷は基本的に据え置き。大画面では拡大による粗さ、PC 16:9では少し上下がクロップされる。スマホ縦は全体表示のため上下に余白ができる。

画像生成指示：暗い西洋ダークファンタジーのHUD用小紋章。透明背景、赤い多面宝石、古い黒鉄の環、控えめな古金の象嵌。文字なし、64pxでも形が読める。WYD3の金/黒UIに合わせた。
