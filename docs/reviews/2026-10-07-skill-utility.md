# 全8職・72技能の発動調査（2026-10-07）

## 測り方

- `node tools/skill-audit.js`：Lv40、技能Lv6、1つずつON。30秒間、HP55%、動かない硬い敵3体に自動戦闘。基本攻撃・手下の寄与も併記する。被弾なしで、瀕死時の技能や屍体を使う技能の評価には使わない。
- `node tools/skill-audit-live.js`：8職をそれぞれ新規セーブから10分自動育成。敵の出現・装備・被弾を含める。乱数を固定していないので職間の順位や前後の総火力の差は比較しない。
- 追加の `tools/skill-utility-test.js`：敵が本体から180離れて骸骨・人形が前線にいる条件で、自動発動・命中・終幕の優先順位を検査。

## 判定と変更

| 職業 | 調査で見えたこと | 対応 |
| --- | --- | --- |
| バーバリアン | 旋風・突進・召喚など発動。戦いの号令は常時能力に反映し、使用回数0が正常 | 変更なし |
| ソーサレス | 静電気の場は距離140の本体中心では30秒で1回、約100ダメージ | 270以内の敵を起点に半径95、最大3体へ毎秒放電。単独計測30回、約4,600ダメージ |
| ネクロマンサー | 骨の嵐は屍体なしの定点計測で0回だが通常の10分育成で98回。腐敗の気は本体近くに敵がいないと30秒で1回 | 骨の嵐は屍体優先、屍体なしなら前線の骸骨から0.8倍の嵐。腐敗は本体と骸骨を起点にし、重複範囲も1回だけ命中 |
| パラディン | 攻撃オーラ・祈り・鎚を確認。信仰の力は常時能力なので使用回数0が正常 | 変更なし |
| アサシン | 急襲・罠・追撃を確認。防御技能は被弾時にだけ使う | 変更なし |
| ドルイド | 変身と手下が定点計測でも有効。フォームは現在のワールドを設定して検証 | 変更なし |
| 冥爆術師 | 仕込み・誘爆・使い魔が発動。影の外套は被弾時にだけ使う | 変更なし |
| 傀儡師 | 終幕は人形HP40%以下が条件で、命の糸に先に修復されると発動しない | 終幕を修復より先に判定し、爆発直後の即時再召喚を防ぐ。人形の再召喚待ち時間は従来どおり |

骨の嵐と終幕は定点30秒では依然0回。前者は通常育成で発動し、後者は人形に被弾が必要なため、ゼロをそのまま「死に技能」とは判定しない。HP回復・防御・変身・召喚はダメージ集計だけで判定しない。各技能IDと既存セーブ形式は維持。

## 確認

- `node tools/run-tests.js`：27 / 27 成功。
- 10分自動育成：8職すべて完走、ブラウザエラー0。改修後のネクロマンサーの骨の嵐は121回（改修前98回、乱数差を含む）。
- 遠距離の静電気、骸骨起点の骨の嵐・腐敗、人形HP30%時の終幕と再召喚待ち時間を回帰テストで確認。
