# 能力の効き目の測り直し（死にステ直し①〜③のあと）2026-10-10

前の調査（`docs/reviews/2026-10-09-stat-weights.md`）と同じ測り方で、#173〜#176 のあとの main を測り直した。結果はおすすめ装備の重み（`data/optimizer.js`）に使った。

- 生データ：`docs/reviews/2026-10-10-stat-weights/<職業>.json`（8職業×84ビルド、乱数4つずつ）
- まとめ：`node tools/stat-weights-summary.js docs/reviews/2026-10-10-stat-weights`
- 重みの作り方：`node tools/optimizer-weights.js docs/reviews/2026-10-10-stat-weights`

## 前とのちがい（追加能力1つぶんで何%伸びるか・全ビルドの中央値）

| 能力 | 火力：前 | 火力：後 | 生存：前 | 生存：後 |
|---|---|---|---|---|
| 攻撃力 | +6.4 | +6.6 | +2.0 | +0.2 |
| 防御 | 0 | 0 | **+9.5** | **+4.1** |
| 最大HP | 0 | 0 | +2.0 | **+3.1** |
| HP回復 | 0 | 0 | +0.6 | **+3.2** |
| 攻撃速度 | +0.4 | +0.8（猛攻を使うビルドは +3.6） | +0.4 | +0.1 |
| 会心率 | +2.5 | +2.4 | +0.9 | +0.1 |
| スキル威力 | +4.8 | +4.7 | +1.3 | 0 |

- 生存は「防御だけ」から「防御・最大HP・HP回復がほぼ同じ」になった。攻撃力・スキル威力が生存に効かなくなったのは、吸血に上限がついたため（狙いどおり）。
- 通常攻撃型のビルド：672通り中 14 → **57**、与ダメージ/秒の中央値 1,160 → **7,538**（スキル型は 9,102）。
- 攻撃速度アップのスキル8つは、どの職業でも死にスキルではなくなった。
