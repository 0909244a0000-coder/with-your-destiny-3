# 能力の効き目の調査（おすすめ装備の重みの裏どり）2026-10-09

持ち主の指示：「おすすめ装備」の重みを決める前に、キャラごと・スキル（ビルド）ごとに必要な能力がちがうかを実測で裏どりする。どのキャラ・どのビルドでも同じなら、そこのバランスも見直す。

- 道具：`tools/stat-weights.js`（計測）、`tools/stat-weights-summary.js`（まとめ）
- 生データ：`docs/reviews/2026-10-09-stat-weights/<職業>.json`（8職業×84ビルド＝672通り、乱数4つずつ）

## 結論（強い順）

### 1. 職業による差はほぼない。どの職業でも「攻撃力がいちばん効く」（裏どりできた）
- 火力は、7職業すべてで **攻撃力 +6.0〜6.6%／1つぶん** がいちばん大きい。ビルドを変えてもほとんど動かない（10%点〜90%点で ±0.3）。
- 次が スキル威力（+4.8%）、会心率（+2.5%）。攻撃速度は +0.4%、移動速度・防御・HP・回復は 0。
- 例外は **傀儡師** だけ。人形が本体の HP・防御から強くなるので、防御（+2.7%）・HP（+1.4%）が火力にも効き、攻撃力は +2.4% に下がる。
- → 「職業ごとに欲しい能力がちがう」は、今のしくみでは **成り立っていない**（傀儡師を除く）。

### 2. ビルドで変わるのは「スキル型か、通常攻撃型か」の1本だけ
- ダメージを出すスキルが1つでもONなら、スキル威力が +4.8% 効き、攻撃速度はほぼ 0（+0.4%）。
- ダメージスキルがない「通常攻撃型」だけ、攻撃速度が +3.5% 効き、スキル威力は 0。
- ただし通常攻撃型は **672通り中14通り** しかなく、与ダメージ/秒の中央値は **1,160**（スキル型は **7,418**。約6分の1）。実際には選ぶ理由がない。
- → **攻撃速度は、ほぼ全部のビルドで効かない能力**になっている（スキルのクールダウンや発動の速さに関係しないため）。

### 3. 生存は「防御」が飛びぬけて強い。ただし敵の強さで 0 になる崖がある
- 危険度5・業火の玉座：**防御 +9.5%／1つぶん**、HP +2.0%、攻撃力 +2.0%（吸血のぶん）、スキル威力 +1.3%、会心 +0.9%、**HP回復 +0.6%**。
- 1点あたりで比べると、防御は HP の約19倍。回復はほぼ効かない。
- 危険度1では、防御は **0**（パラディン）になる。敵の攻撃が弱いと、ダメージがすでに下限（攻撃力の15%。`data/items.js` の combat.minDamageRatio）に張りついていて、防御を足しても減らないため。
- → 防御は「効く所では強すぎ、効かない所では0」。HP回復は、どこでもほぼ効かない。

### 4. 移動速度は「遠くから戦う職業の生存」にだけ効く
- ソーサレスは生存 +14%（中央値。ビルドによって0〜34%）、冥爆術師は +6.5%。距離をとる動きが長くなるため。ほかの職業は 0。
- 一方、ソーサレスの火力は **−2.6%**（離れているあいだは攻撃しないため）。

## 今の重み（PR #171 の data/optimizer.js）とのずれ

1点あたりの重みに直して比べた（火力は攻撃力＝6、防御は防御＝5 にそろえた）。

| 能力 | 火力：今 | 火力：実測（スキル型） | 防御：今 | 防御：実測 |
|---|---|---|---|---|
| 攻撃力 | 6 | 6 | 1.5 | 1.1 |
| 防御力 | 1 | 0 | 5 | 5 |
| 最大HP | 0.2 | 0 | 0.8 | **0.26** |
| HP回復/秒 | 1 | 0 | 8 | **1.0** |
| 攻撃速度 | 3 | **1.2**（通常攻撃型は 10） | 0.5 | 0.6 |
| 会心率 | 3 | **16** | 0.5 | **3.3** |
| 移動速度 | 0.3 | 0 | 0.3 | 0（ソーサレスは約23） |
| スキル威力 | 1.6 | **9.1** | 0.3 | **1.4** |

- **スキル威力は約6倍、会心率は約5倍、低く見ていた。** スクショの「+10 太古の業火の杖 → 太古の雷帝の大剣（+25点。攻撃力 +302点・スキル威力 −262点）」は、実測の重みなら杖のままのほうが上になる。
- 防御タブでは、HP と HP回復を高く見すぎていた。
- 自動装備の重み（`data/items.js` の autoEquip.weights）も、スキル威力・会心率を低く見る点は同じ。

## 測り方（くわしく）
- 条件：Lv50。選んだ3スキルだけ Lv10 でON（ほかは Lv0。熟練・型・秘技・星座・宝石・パラゴンなし）。レジェンド9部位（Lv50。乱数で4組）。最後のエリア「業火の玉座」・危険度5の敵6体（倒れないようにHPを固定）。敵の出現・階・祠・裂け目は止めた。
- 火力：敵の攻撃を0にして、40秒の与ダメージ/秒（召喚・罠・効果こみ）。
- 生存：敵はふつうに攻撃する。40秒の被ダメージ/秒・回復/秒・最大HPから「20秒もつ敵の強さ」＝（最大HP÷20＋回復/秒）÷被ダメージ/秒 を出して比べた。+10% なら、1割強い敵に同じだけ耐えられる。回復がむだにならないよう、HP は7割より上に戻さない。
  - はじめは「倒れるまでの秒数」で測ったが、守りのスキルが間に合うかどうかで6秒か36秒かに飛び、比べられなかったのでやめた。
- 能力の足し方：1つの能力を「Lv50 の追加能力の平均×4」だけ帯に足して、足す前との差（%）を4で割った（＝追加能力1つぶん）。足す前と後で同じ乱数を使った。
- ばらつき：乱数4つの平均の誤差は、ほとんど ±0.5% 以内。

## わかっていないこと（この調査の限界）
- **対人（アリーナ）は測っていない**。対人のダメージ上限・回復の補正があるので、別に測る必要がある。
- **危険度15では、生存の測り方がこわれる**：HP7割から一撃で倒れることがあり（パラディン・ソーサレスとも4回）、被ダメージ/秒の比べ方が成り立たない。強い敵の「一撃に耐える」ぶん（HP の効き目）は、この測り方では小さく出ている可能性がある。
- 敵は倒れないので、「早く倒して身を守る」ぶんは生存に入っていない（火力の能力は、実際にはもう少し生存にも効く）。
- 型（ルーン）・熟練・秘技・パラゴン・セット・ユニーク・宝石の特殊効果は入れていない。会心ダメージを上げる効果がある装備では、会心の値は変わる。
- スキルは3つとも Lv10。育成途中は測っていない。

## 決めてほしいこと（持ち主へ）
1. **おすすめ装備の重みの出し方**
   - 案A：実測の中央値で、目的ごとの重みを1つずつ置きかえる（かんたん）。
   - 案B：今のビルドを見て切りかえる。ダメージスキルがONか（スキル型／通常攻撃型）、傀儡師か、遠くから戦う職業か（移動速度）。実測で差が出たのはこの3つだけなので、表は小さくてすむ。
2. **バランスを見直すか**（「どの職業でも同じならバランスも変える」の条件には当たっている）
   - 攻撃速度がスキルに効かない：攻撃速度でスキルのクールダウンや発動も速くするか、追加能力の候補から外す／弱いぶん数値を上げるか。
   - 防御が強すぎて、HP・HP回復が弱すぎる：下限15%の崖の形を変えるか（例：防御で割合で減らす）、HP・回復の数値を上げるか。
   - 職業ごとに欲しい能力がちがわない：職業専用の伸び方（例：ソーサレスはスキル威力が伸びやすい、など）を足すか、今のまま（装備えらびは単純でよい）とするか。
   - 反対の見方：今のままでも「攻撃力とスキル威力を集める」とわかりやすく、職業ごとの差はスキルの動きでもう出ている。装備の能力まで分けると、自動装備・おすすめが職業ごとに複雑になる。
