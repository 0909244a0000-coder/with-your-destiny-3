- 職業のスキルは「しくみ（kind）」を共有する。新しい職業は `data/classes.js` に足すだけで作れる。ユニーク装備の説明は `{skill:しくみ}` で職業ごとのスキル名になる

- データの id（スキル・装備・特殊効果・ユニーク）は、名前を変えても変えない（セーブが壊れないように）。名前を変えたら、古いセーブの装備名を直す表 `data/items.js` の `renamedWords` に足す
