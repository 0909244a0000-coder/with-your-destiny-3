# With Your Destiny Ⅲ

長く遊びながら育てていく、オート戦闘のハクスラ（ディアブロ風）ゲームです。設計図は [docs/SPEC.md](docs/SPEC.md)。

## 遊び方
- `index.html` をブラウザで開くだけで遊べます（PC向け）。
- 戦闘は自動です。プレイヤーは **装備** と **スキル** を選びます。
  - 持ち物の装備を左クリック → 装備する／右クリック → 捨てる
  - レベルアップでもらえるスキルポイントで、スキルを強くする
  - 最高の危険度で敵を倒し続けると、次の危険度が解放されます
- セーブは自動（ブラウザに保存）。「最初から」で消せます。

## GitHub Pages で公開する
リポジトリの Settings → Pages → 「Deploy from a branch」で `main` ／ `/(root)` を選ぶ。

## 数値を変えたいとき
`data/` の中のファイルを書きかえます（例：敵の強さは `data/enemies.js`、装備の特殊効果は `data/effects.js`）。
